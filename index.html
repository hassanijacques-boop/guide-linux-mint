Installer Linux Mint 22.3 « Zena »

Remplacer Windows sur le PC · sans rien perdre

⏱ ~1 h 30 💾 Clé USB 4 Go min. Langue : français
🛑 Lis ces 3 lignes avant de toucher à quoi que ce soit On va effacer Windows et tous les fichiers du disque (Bureau, Documents, Images, Téléchargements, Vidéos).
Ce qui est protégé : le disque Y: et tes vidéos de formations achetées — on n'y touche pas.
Ce que tu dois sauvegarder toi-même : photos, papiers, dossiers de l'école, CV… sur un disque externe, une clé USB ou Google Drive. Fais-le avant l'étape 5.
0

Ce qu'il te faut

  • 1 clé USB de 4 Go minimum — elle sera complètement effacée (prends-en une vide ou dont tu n'as plus besoin).
  • Internet pour télécharger 2,9 Go (le plus long de tout le guide).
  • Le PC branché sur secteur.
  • Ton téléphone à côté, pour m'envoyer les photos d'écran.
  • Idéalement un câble Ethernet (ou ton téléphone en partage de connexion) au cas où le Wi-Fi ne serait pas reconnu.
⚡

Le plus simple : un seul double-clic (remplace les étapes 1, 2 et 3)

Au lieu de télécharger et configurer à la main, utilise cet outil. Il fait tout le sale boulot :

  • il télécharge Linux Mint (2,88 Go) — et reprend si la connexion coupe ;
  • il vérifie le fichier (empreinte SHA256) pour qu'il ne soit pas corrompu ;
  • il télécharge Rufus et l'ouvre avec Linux Mint déjà chargé.
⬇ Télécharger l'outil (zip, 6 Ko)Preparer-Cle-Mint.zip · à extraire puis double-clic sur Preparer-Cle-Mint.bat

Puis : clic droit sur le zip → Extraire tout → double-clic sur Preparer-Cle-Mint.bat → si Windows demande, Oui. Une fenêtre noire s'ouvre : ne la ferme pas pendant le téléchargement.

Il te restera 3 clics dans Rufus 1) « Périphérique » = ta clé USB (4–16 Go, jamais 500 Go) — 2) DÉMARRER puis OK, et « mode image ISO » si on te le propose — 3) attendre la fin puis FERMER.

Tu préfères tout faire à la main ? Les étapes 1, 2 et 3 ci-dessous restent valables — même résultat.

2

Télécharger Rufus (le graveur de clé USB)

Rufus est un petit programme gratuit qui met Linux sur la clé USB. Pas d'installation : il s'ouvre tout seul.

⬇ Télécharger Rufus 4.15Site officiel de l'auteur (GitHub) · rufus-4.15.exe
3

Graver la clé USB (3 clics)

  1. Branche la clé USB.
  2. Double-clic sur rufus-4.15.exe → une fenêtre s'ouvre.
    Si Windows demande l'autorisation : clique Oui.
  3. En haut, « Périphérique » : vérifie que c'est bien ta clé USB (regarde la taille, ex. 8 Go). ⚠️ Rufus va effacer ce disque — c'est la clé, jamais le disque dur.
  4. Sur « Sélection de l'image » → SÉLECTION → choisis le fichier linuxmint-22.3-cinnamon-64bit.iso dans Téléchargements.
  5. Laisse tout le reste tel quel. Vérifie juste :
    Schéma de partition = GPT · Système de destination = UEFI (non CSM) · Système de fichiers = FAT32
  6. Clique DÉMARRER.
  7. Si une fenêtre « Mode image ISO / DD » s'ouvre → choisis « Écrire en mode image ISO (recommandé) » → OK.
  8. Confirme l'effacement de la clé → attends la fin (2 à 10 min) → FERMER.
Le piège à éviter Si Rufus demande « télécharger un fichier supplémentaire » (ex. ldlinux), clique Oui : c'est normal. En revanche, si dans « Périphérique » tu ne vois pas ta clé mais un disque de 500 Go → STOP, tu t'es trompé de disque, ferme Rufus et rebranche la clé.
4

Noter ta clé Windows (5 minutes, utile plus tard)

On efface Windows, mais la clé de licence reste dans la machine. Autant la garder écrite quelque part :

  1. Clique sur Démarrer, tape powershell, ouvre Windows PowerShell.
  2. Copie-colle cette ligne et appuie sur Entrée :
(Get-CimInstance SoftwareLicensingService).OA3xOriginalProductKey

Si une suite de 25 caractères s'affiche (ex. XXXXX-XXXXX-XXXXX-XXXXX-XXXXX), envoie-la moi par message ou note-la sur un papier. Si rien ne s'affiche, ce n'est pas grave : passe à la suite.

5

Sauvegarder tes fichiers personnels

  • Bureau, Documents, Images, Téléchargements, Vidéos personnelles
  • Photos et vidéos de famille
  • Dossiers de l'école, fiches, préparations, LSU
  • CV, papiers administratifs (impôts, CAF, MSA, assurances)
  • Favoris / mots de passe du navigateur (si tu y tiens)
Le disque Y: n'est PAS une sauvegarde On le garde intact, mais si le disque tombe en panne tout part avec. Copie au moins tes photos et papiers sur un disque externe ou dans Google Drive. C'est la seule étape vraiment irréversible.
6

Démarrer le PC sur la clé USB

  1. Garde la clé USB branchée. Redémarre le PC (Démarrer → Redémarrer, pas « Arrêter »).
  2. Dès que l'écran s'éteint puis se rallume, tapote plusieurs fois la touche F12.
    Ton clavier est un QWERTY externe : sur certains PC il faut Fn + F12. Sinon essaie F10, F11 ou Échap (Esc). La bonne touche est souvent écrite en bas de l'écran au démarrage.
  3. Un menu « Boot » s'ouvre → choisis la ligne USB / UEFI: nom de ta clé → Entrée.
  4. Un menu noir apparaît avec « Start Linux Mint » → appuie sur Entrée (ou attends 10 secondes).
  5. Linux Mint démarre sans rien installer. Tu arrives sur un bureau avec une icône « Installer Linux Mint ».
Si le PC démarre sur Windows comme d'habitude Le menu de démarrage ne s'est pas ouvert. Éteins le PC, rallume et retape Fn + F12 plus vite, dès le premier logo. Si ça refuse encore, dis-le-moi : on passera par le réglage de l'ordre de démarrage dans le BIOS.
Si un message rouge « Security Violation » apparaît C'est le Secure Boot. Note le message et envoie-moi une photo : on le désactivera dans le BIOS (menu Security → Secure Boot → Disabled).

7 · ⛔ Point de contrôle — NE PAS INSTALLER TOUT DE SUITE

C'est ici que tout se joue. On vérifie ensemble où sont tes vidéos avant d'effacer quoi que ce soit.

Sur le bureau Linux Mint, fais ceci :

  1. Ouvre un terminal : Ctrl + Alt + T (ou menu → Terminal).
  2. Tape exactement cette ligne, puis Entrée :
lsblk -o NAME,SIZE,FSTYPE,LABEL
  1. Prends une photo de l'écran avec ton téléphone et envoie-la moi.
  2. J'te réponds avec la liste exacte : ce qu'on garde (la partition de tes vidéos + le démarrage) et ce qu'on supprime (Windows).

Je te dirai aussi combien d'espace libre tu auras pour Linux. Tant que je n'ai pas vu cette photo : tu ne cliques nulle part.

Installer Linux Mint

Une fois que je t'ai donné le feu vert, double-clique sur « Installer Linux Mint » sur le bureau.

Principe de ce qu'on va faire (pour que tu comprennes) Le disque est découpé en « morceaux » (partitions). On va garder le morceau de démarrage et le morceau de tes vidéos, supprimer le morceau de Windows, et installer Linux dans l'espace libéré. C'est pour ça qu'on regarde avant d'agir.

À la fin : « Redémarrer maintenant ». Quand l'écran le demande, débranche la clé USB et appuie sur Entrée.

9

Première fois sous Linux Mint

  1. Connecte le Wi-Fi (icône en bas à droite).
  2. Menu → Mises à jour → installe tout (peut prendre 15–30 min).
  3. Menu → Logithèque → installe VLC (pour lire tes vidéos de formation) et LibreOffice (déjà installé : documents, tableur, présentations).
  4. Tes vidéos sont dans le disque Y: → ouvre le Gestionnaire de fichiers, elles apparaissent dans la colonne de gauche (souvent « 195 GB Volume »). Double-clic sur une vidéo → elle s'ouvre avec VLC.
  5. Menu → Timeshift → configure une sauvegarde du système (recommandé, 20 min).
Tu es arrivé Windows n'est plus là, tes vidéos sont toujours là, et le PC est plus rapide. Envoie-moi une photo de ton bureau : je vérifie que tout est propre et je te donne les 3 réglages à faire ensuite (langue, dossiers, polices).

Les 4 règles d'or 1. On ne clique jamais « Effacer le disque ». — 2. On vérifie avec la photo avant chaque étape qui modifie le disque. — 3. La clé USB sera effacée, le disque dur ne l'est pas (sauf si on le décide). — 4. En cas de doute : stop, message.
